About

DailChat-Mysqlは、PythonとMySQLを利用して動作する AIチャットボットです。

AIとの会話だけでなく、設定情報や長期記憶を MySQL上で管理できる構成となっており、 Linuxサーバー上で継続的に利用することを想定しています。

GitHub Releasesでは、Linux環境へ導入できる RPMパッケージも公開しています。

Features

MySQL Data Management

Dailの設定情報や各種データを MySQL上で管理します。

Long-term Memory

保存された情報を利用し、 過去の情報を保持した継続的な対話に対応します。

Gemini API

Gemini APIを利用してAIの応答を生成します。 使用するモデルやAPIキーなどは設定から変更できます。

Dropbox Integration

Dropboxとの連携に対応しています。 設定によって機能の有効・無効を切り替えられます。

System Prompt

システムプロンプトをファイルとして管理し、 ユーザー環境に応じたAI設定を行えます。

Linux

Linuxサーバー上での利用を想定して設計されています。 RPMパッケージによる導入にも対応しています。

CLI

インストール完了後は、 dail コマンドから起動できます。

Open Source

ソースコードはGitHub上で公開されています。 ソースからのセットアップも可能です。

Installation

Latest RPM

最新版のRPMパッケージは GitHub Releasesからダウンロードできます。

Download Latest Release

RPM Package

GitHub Releasesから最新版の .rpm ファイルをダウンロードします。

RPMファイルを保存したディレクトリで、 以下のコマンドを実行します。 

sudo dnf install ./dail-*.rpm

依存関係がある場合は、 dnf によって必要なパッケージも処理されます。

Start Dail

インストール完了後は、 以下のコマンドでDailを起動します。 

dail

Update

新しいRPMをダウンロードした場合も、 同様に dnf install を実行することで更新できます。 

sudo dnf install ./dail-*.rpm

Install from Source

RPMを使用せず、 ソースコードからセットアップすることもできます。 

git clone https://github.com/Divings/DailChat-Mysql.git
cd DailChat-Mysql

セットアップスクリプトへ実行権限を付与します。 

chmod +x setup.sh

セットアップを実行します。 

./setup.sh
RPMパッケージを利用する場合は、 GitHub Releasesで公開されている最新版の利用を推奨します。

Configuration

DailChat-Mysqlでは、 データベースやAI、Dropboxなどの設定を 設定ファイルから管理します。

Database

MySQLへの接続情報を設定します。 

[DATABASE]
host = localhost
port = 3306
user = Users
password = Password
database = Database

実際の環境に合わせて、 MySQLユーザー名、パスワード、 データベース名などを変更してください。

Gemini API

AI応答の生成にはGemini APIを使用します。

APIキーや使用するモデルなどは、 Dailの設定から指定します。

System Prompt

Dailが使用するシステムプロンプトは 専用ファイルとして管理できます。

システムプロンプトを編集することで、 AIの基本的な役割や応答方針を変更できます。

Dropbox

Dropbox機能を利用する場合は、 Dropbox用の認証情報を設定します。

Dropbox機能を使用しない場合は、 設定から無効化できます。

Security

DailChat-Mysqlでは、 APIキーやデータベースの認証情報などを扱います。

以下のような情報を 公開Gitリポジトリへコミットしないでください。 

Gemini API Key
MySQL Password
Dropbox App Key
Dropbox Refresh Token
その他の認証情報

設定ファイルをGitで管理する場合は、 秘密情報を除外するか、 .gitignore などを適切に設定してください。
